# Entregable 4 - Proyecto Web

## Descripción

Este proyecto corresponde al cuarto entregable del curso de desarrollo web. En él se aplican conceptos de maquetación, diseño responsivo y organización de código utilizando tecnologías frontend.

El objetivo principal es construir una página web con una estructura clara, adaptable a diferentes dispositivos y siguiendo buenas prácticas de desarrollo.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Diseño Responsive
- Git y GitHub para control de versiones

## Características

- Estructura semántica utilizando etiquetas HTML5.
- Diseño adaptable para dispositivos móviles y escritorio.
- Organización de estilos mediante archivos CSS separados.
- Uso de Flexbox y Grid para la distribución de elementos.
- Aplicación de buenas prácticas de código y organización de carpetas.

## Objetivo del proyecto

Fortalecer los conocimientos de desarrollo frontend mediante la creación de una interfaz web moderna, aplicando conceptos de diseño, estructura y estilos aprendidos durante el curso.
